# comment-admin 规格

## ADDED Requirements

### Requirement: 后台评论列表
系统 SHALL 在后台提供评论管理页面（`/admin/comments`，需管理员登录）：分页展示全部评论，每条包含评论内容、来源标签（知识库/小记）、来源标题、评论人昵称、评论人邮箱、层级（顶层/回复）、创建时间；支持按来源类型（全部/知识库/小记）筛选。

#### Scenario: 查看评论列表
- **WHEN** 管理员打开后台评论管理页
- **THEN** 页面分页展示评论列表，每条评论显示内容、来源标签、来源标题、评论人昵称与邮箱、层级、时间

#### Scenario: 按来源筛选
- **WHEN** 管理员选择筛选条件「知识库」或「小记」
- **THEN** 列表仅展示对应来源的评论

#### Scenario: 未登录访问后台评论页
- **WHEN** 非管理员（无 admin token）访问 `/admin/comments` 或其 API
- **THEN** 前端跳转管理员登录页，API 返回 401

### Requirement: 来源标注与一键跳转
后台评论列表 SHALL 标注每条评论来自知识库还是小记，并展示来源标题；来源标题 SHALL 可点击，一键跳转到对应前台页面（知识库文章详情 `#/articles/:slug` 或小记详情 `#/xiaoji/:slug`，新窗口打开）。

#### Scenario: 跳转知识库文章
- **WHEN** 管理员点击某条 targetType=article 评论的来源标题
- **THEN** 新窗口打开该文章的前台详情页

#### Scenario: 跳转小记
- **WHEN** 管理员点击某条 targetType=note 评论的来源标题
- **THEN** 新窗口打开该小记的前台详情页

#### Scenario: 来源内容已被删除
- **WHEN** 某条评论对应的文章或小记已从数据库删除
- **THEN** 列表该行来源标题显示「已删除」且不可点击跳转

### Requirement: 删除评论（顶层连带回复）
后台 SHALL 支持删除单条评论；当被删除的是顶层评论时，系统 MUST 在同一事务中连带删除其下全部回复。

#### Scenario: 删除回复评论
- **WHEN** 管理员删除一条回复（parentId 非空）
- **THEN** 仅该条回复被删除

#### Scenario: 删除顶层评论连带回复
- **WHEN** 管理员删除一条顶层评论
- **THEN** 该评论及其下所有回复在同一事务中全部删除

#### Scenario: 删除后前台同步
- **WHEN** 管理员删除评论后访客刷新对应详情页
- **THEN** 被删除的评论（及其连带回复）不再展示
