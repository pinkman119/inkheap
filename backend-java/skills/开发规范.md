# 开发规范
## MVC 层
使用 【Controller - Service - Mapper】 的架构

### Controller
1. 使用统一的响应结构体 ResponseBody，并封装 ResultUtils 工具类，封装公共静态方法来构造 ResponseBody。
2. 请求参数如果过多，基于每个业务，创建独立的实体对象进行参数接收；如果参数只有2个以内，那么可以使用 @RequestParam 接收
3. Controller 层不要写业务代码，最多只做参数校验的逻辑
4. 如果指定对某个实体进行增、删、改、查，尽可能使用【路径变量】来接收 ID

```java
@RestController
@RequestMapping("/user")
public class UserController {

    @Resource
    private UserService userService;

    /**
     * 获取当前登录用户
     *
     * @return 当前用户
     */
    @GetMapping("get/login")
    public BaseResponse<UserVo> getLoginUser(HttpServletRequest request) {
        return ResultUtils.ok(userService.getLoginUser());
    }

    /**
     * 用户注册
     * @param registerRequest
     * @return
     */
    @PostMapping("register")
    @Log(module = LogModuleEnum.USER, description = "用户注册")
    public BaseResponse<Long> register(@RequestBody UserRegisterRequest registerRequest) {
        String userAccount = registerRequest.getUserAccount();
        String userPassword = registerRequest.getUserPassword();
        String checkPassword = registerRequest.getCheckPassword();

        return ResultUtils.ok(userService.register(userAccount, userPassword, checkPassword));
    }

    /**
     * 用户登录
     * @param request 用户登录请求
     * @return
     */
    @PostMapping("login")
    @Log(module = LogModuleEnum.USER, description = "用户登录")
    public BaseResponse<UserVo> login(@RequestBody UserLoginRequest loginRequest, HttpServletRequest request) {
        String userAccount = loginRequest.getUserAccount();
        String userPassword = loginRequest.getUserPassword();

        return ResultUtils.ok(userService.login(userAccount, userPassword, request));
    }

    /**
     * 根据用户 ID 删除用户
     * @param deleteRequest
     * @return
     */
    @PostMapping("delete")
    @Log(module = LogModuleEnum.USER, description = "删除用户")
    @Auth(allow = RoleEnum.ADMIN)
    public BaseResponse<Boolean> delete(@RequestBody DeleteRequest deleteRequest) {
        return ResultUtils.ok(userService.removeById(deleteRequest.getId()));
    }

    /**
     * 查询用户列表
     * @param userQueryRequest 用户查询请求对象
     * @return 用户列表
     */
    @PostMapping("list/page/vo")
    @Auth(allow = RoleEnum.ADMIN)
    public BaseResponse<Page<UserVo>> listUsers(@RequestBody UserQueryRequest userQueryRequest) {
        return ResultUtils.ok(userService.getUserList(userQueryRequest));
    }
}
```

### Service
1. 方法注释都写在 Service 中，ServiceImpl 不写方法注释，只写方法内的代码注释。
2. ServiceImpl 中每个方法的代码注释，要用 【1. 2. 3.】 这样的单行注释来划分方法的执行逻辑，并且步骤之间要空一行。
3. 每个实体类对应的 Service，都定义 getQueryWrapper 方法，提供基本的查询逻辑。
    1. 如果是多表关联复杂查询，将 sql 写入 xml 文件中。

```java
@Override
public QueryWrapper getQueryWrapper(UserQueryRequest userQueryRequest) {
    QueryWrapper queryWrapper = new QueryWrapper();
    String id = userQueryRequest.getId();
    String userAccount = userQueryRequest.getUserAccount();
    String userName = userQueryRequest.getUserName();
    String userProfile = userQueryRequest.getUserProfile();
    String userRole = userQueryRequest.getUserRole();

    String sortField = userQueryRequest.getSortField();
    String sortOrder = userQueryRequest.getSortOrder();

    return queryWrapper
            .eq(User::getId, id, StrUtil.isNotBlank(id))
            .like(User::getUserAccount, userAccount, StrUtil.isNotBlank(userAccount))
            .like(User::getUserName, userName, StrUtil.isNotBlank(userName))
            .like(User::getUserProfile, userProfile, StrUtil.isNotBlank(userProfile))
            .eq(User::getUserRole, userRole, StrUtil.isNotBlank(userRole))
            .orderBy(sortField, "ascend".equals(sortOrder));
}
```

完整示例代码：

```java
@Service
public class UserServiceImpl extends ServiceImpl<UserMapper, User>  implements UserService{
    private static final String LOGIN_USER = "LOGIN_USER";

    @Override
    public UserVo login(String userAccount, String password, HttpServletRequest request) {
        // 1、查询用户是否存在
        QueryWrapper queryWrapper = new QueryWrapper();
        queryWrapper.eq(User::getUserAccount, userAccount);
        queryWrapper.eq(User::getUserPassword, encryptPassword(password));
        User user = this.getOne(queryWrapper);
        if (user == null) {
            throw new BusinessException("用户名或密码错误！");
        }

        // 2、记录用户状态，记录到 session 中
        UserVo userVo = getUserVo(user);
        request.getSession().setAttribute(LOGIN_USER, userVo);

        return userVo;
    }

    @Override
    public UserVo getLoginUser(HttpServletRequest request) {
        Object attribute = request.getSession().getAttribute(LOGIN_USER);
        if (attribute == null) {
            throw new BusinessException(ErrorCode.NOT_LOGIN);
        }
        return (UserVo) attribute;
    }

    @Override
    public UserVo getLoginUser() {
        // 1、 从当前线程上下文中获取 RequestAttributes
        ServletRequestAttributes attributes = (ServletRequestAttributes) RequestContextHolder.getRequestAttributes();

        // 2、 防御性编程：防止在非 Web 请求线程（如定时任务、异步线程）中调用
        if (attributes == null) {
            throw new BusinessException(ErrorCode.SYSTEM_ERROR, "无法获取当前请求上下文");
        }

        // 3、 获取 HttpServletRequest
        HttpServletRequest request = attributes.getRequest();

        // 4、 原有的 Session 获取逻辑
        Object attribute = request.getSession().getAttribute(LOGIN_USER);
        if (attribute == null) {
            throw new BusinessException(ErrorCode.NOT_LOGIN);
        }

        return (UserVo) attribute;
    }

    @Override
    public Page<UserVo> getUserList(UserQueryRequest userQueryRequest) {
        QueryWrapper queryWrapper = this.getQueryWrapper(userQueryRequest);

        // 1、分页查询
        int pageNum = userQueryRequest.getPageNum();
        int pageSize = userQueryRequest.getPageSize();
        Page<User> userPage = this.page(Page.of(pageNum, pageSize), queryWrapper);

        // 2、转为 vo
        List<UserVo> userVoList = getUserVoList(userPage.getRecords());
        Page<UserVo> userVoPage = Page.of(pageNum, pageSize, userPage.getTotalRow());
        userVoPage.setRecords(userVoList);

        return userVoPage;
    }

    @Override
    public List<UserVo> getUserVoList(List<User> userList) {
        return userList.stream().map(this::getUserVo).collect(Collectors.toList());
    }

    @Override
    public UserVo getUserVo(User user) {
        UserVo userVo = new UserVo();
        BeanUtil.copyProperties(user, userVo);
        return userVo;
    }

    private String encryptPassword(String password) {
        // 盐值，混淆密码
        final String SALT = "lyh";
        return DigestUtils.md5DigestAsHex((password + SALT).getBytes(StandardCharsets.UTF_8));
    }

    @Override
    public QueryWrapper getQueryWrapper(UserQueryRequest userQueryRequest) {
        QueryWrapper queryWrapper = new QueryWrapper();
        String id = userQueryRequest.getId();
        String userAccount = userQueryRequest.getUserAccount();
        String userName = userQueryRequest.getUserName();
        String userProfile = userQueryRequest.getUserProfile();
        String userRole = userQueryRequest.getUserRole();

        String sortField = userQueryRequest.getSortField();
        String sortOrder = userQueryRequest.getSortOrder();

        return queryWrapper
                .eq(User::getId, id, StrUtil.isNotBlank(id))
                .like(User::getUserAccount, userAccount, StrUtil.isNotBlank(userAccount))
                .like(User::getUserName, userName, StrUtil.isNotBlank(userName))
                .like(User::getUserProfile, userProfile, StrUtil.isNotBlank(userProfile))
                .eq(User::getUserRole, userRole, StrUtil.isNotBlank(userRole))
                .orderBy(sortField, "ascend".equals(sortOrder));
    }
}

```

## 实体类
### 通用类
实体类的包统一放在 /model 文件夹下，每个类别在 /model 下单独新建目录。

实体类类别如下：

+ dto：用于接收前端参数的实体类
+ vo：对数据库实体类转换后的对象，如进行数据脱敏、二次计算等
+ entity：数据库实体类，对应数据库实体表

#### dto
接收前端参数，主要用于 Post 请求体参数接收。

在 /dto 目录中，要对每一个业务的接收参数实体创建一个目录，例如 /dto/user，/dto/app，/dto/log

普通的 dto 实体示例如下，一般只需要 @Data 注解即可，因为不返回给前端不需要进行序列化。

```java
@Data
public class AppAddRequest {
    /**
     * 初始提示词
     */
    private String initPrompt;
}

```

涉及继承的 dto 实体示例如下

```java
@EqualsAndHashCode(callSuper = true)
@Data
public class AppQueryRequest extends PageRequest {

    private String appName;

}
```



#### vo 
 	vo 实体一般需要进行序列化，因为要返回给前端。

数据库实体转为 vo 可以封装为一个方法，方便后续的扩展。

```java
@Data
public class UserVo implements Serializable {

    @Serial
    private static final long serialVersionUID = 1L;

    private Long id;
}

@Override

    UserVo userVo = new UserVo();

    return userVo;

```

#### entity
entity 实体一般是在代码内部进行创建，所以为了方便创建，使用 @Builder 注解。

逻辑删除字段需要加 Column 注解，指定为逻辑删除。

```sql
create table if not exists user
(
    id           bigint auto_increment comment 'id' primary key,
    userAccount  varchar(256)                           not null comment '账号',
    userPassword varchar(512)                           not null comment '密码',
    userName     varchar(256)                           null comment '用户昵称',
    userAvatar   varchar(1024)                          null comment '用户头像',
    userProfile  varchar(512)                           null comment '用户简介',
    userRole     varchar(256) default 'user'            not null comment '用户角色：user/admin',
    editTime     datetime     default CURRENT_TIMESTAMP not null comment '编辑时间',
    createTime   datetime     default CURRENT_TIMESTAMP not null comment '创建时间',
    updateTime   datetime     default CURRENT_TIMESTAMP not null on update CURRENT_TIMESTAMP comment '更新时间',
    isDelete     tinyint      default 0                 not null comment '是否删除',
    UNIQUE KEY uk_userAccount (userAccount),
    INDEX idx_userName (userName)
) comment '用户' collate = utf8mb4_unicode_ci;
```

```java
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
@Table("user")
public class User implements Serializable {

    @Serial
    private static final long serialVersionUID = 1L;

    /**
     * id，使用雪花算法自增ID
     */
    @Id(keyType = KeyType.Generator, value = KeyGenerators.snowFlakeId)
    private Long id;

    /**
     * 账号
     */
    private String userAccount;

    /**
     * 编辑时间
     */
    private LocalDateTime editTime;

    /**
     * 创建时间
     */
    private LocalDateTime createTime;

    /**
     * 更新时间
     */
    private LocalDateTime updateTime;

    /**
     * 是否删除
     */
    @Column(value = "is_delete", isLogicDelete = true)
    private Integer isDelete;
}
```

@Data
public class BaseResponse<T> implements Serializable {
    private int code;

    private String msg;

    private T data;

    public BaseResponse(int code, String msg, T data) {
        this.code = code;
        this.msg = msg;
        this.data = data;
    }

    public BaseResponse(int code, T data) {
        this(code, "", data);
    }

    public BaseResponse(ErrorCode code) {
        this(code.getCode(), code.getMessage(), null);
    }
}

import cn.hutool.core.lang.Dict;
import cn.hutool.setting.yaml.YamlUtil;
import com.mybatisflex.codegen.Generator;
import com.mybatisflex.codegen.config.GlobalConfig;
import com.zaxxer.hikari.HikariDataSource;

public class Codegen {
    // 需要自动生成的表名
    private static final String[] GENERATE_TABLES = {"user"};

    public static void main(String[] args) {
        //配置数据源
        Dict dict = YamlUtil.loadByPath("application.yml");
        Map<String, Object> dataSourceMap = dict.getByPath("spring.datasource");
        HikariDataSource dataSource = new HikariDataSource();
        dataSource.setJdbcUrl(String.valueOf(dataSourceMap.get("url")));
        dataSource.setUsername(String.valueOf(dataSourceMap.get("username")));
        dataSource.setPassword(String.valueOf(dataSourceMap.get("password")));

        //创建配置内容，两种风格都可以。
        GlobalConfig globalConfig = createGlobalConfigUseStyle2();

        //通过 datasource 和 globalConfig 创建代码生成器
        Generator generator = new Generator(dataSource, globalConfig);

        //生成代码
        generator.generate();
    }

    // 详细配置见：https://mybatis-flex.com/zh/others/codegen.html
    public static GlobalConfig createGlobalConfigUseStyle2() {
        //创建配置内容
        GlobalConfig globalConfig = new GlobalConfig();

        //设置根包
        globalConfig.getPackageConfig()
                .setBasePackage("cn.yuheng.lyhaicoder.test");

        //设置表前缀和只生成哪些表，setGenerateTable 未配置时，生成所有表
        globalConfig.getStrategyConfig()
                .setGenerateTable(GENERATE_TABLES)
                // 设置逻辑删除字段
                .setLogicDeleteColumn("isDelete");

        //设置生成 entity 并启用 Lombok
        globalConfig.enableEntity()
                .setWithLombok(true)
                .setJdkVersion(21);

        //设置生成 mapper
        globalConfig.enableMapper();
        globalConfig.enableMapperXml();

        //设置 service、controller
        globalConfig.enableService();
        globalConfig.enableServiceImpl();
        globalConfig.enableController();

        // 设置生成注释，比如生成的时间和作者，避免后续多余的代码改动
        globalConfig.getJavadocConfig()
                .setAuthor("<a href=\"https://gitee.com/lxj0749\">LYH</a>")
                .setSince("");

        return globalConfig;
    }
}
