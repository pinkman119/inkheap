# 首页头像上传与归档

## 背景
项目 INKHEAP：NestJS(Express) + Prisma(SQLite) + Vue3(Vite)。目标：本地上传图片存服务器 `files/`，后台首页管理上传头像并回显前台；并配套 OpenSpec 提案工作流与最终归档。

## 关键需求与实现

### 1. 上传能力与 files 表
- 新增 Prisma `File` model（表 `files`）：id/filename/originalName/url/mimeType/size/relativePath/createdAt。
- `HomePage` model 增加 `avatar String? @map("avatar")`。
- 后端 `main.ts` 改为 `NestExpressApplication`，`app.useStaticAssets(join(process.cwd(),'files'), { prefix: '/files' })` 暴露静态目录。
- 新增 `modules/upload`：`POST /api/admin/upload`（FileInterceptor 字段名 `file`，JwtAuthGuard，`fileFilter` 仅 image/*，`limits.fileSize=5MB`），保存到 `files/<YYYY-MM-DD>/<uuid>.<ext>` 并写 `files` 表；返回 `{ id, url, filename, size }`。
- `DELETE /api/admin/upload/:id`（JwtAuthGuard）：按 id 查库→`unlinkSync` 删磁盘→`prisma.file.delete`；记录不存在返回 404，未鉴权 401。

### 2. 替换头像删旧
- `homepage.service.ts` 的 `update`：入参 `avatar` 与库旧值不同且旧值非空时，调用 `uploadService.removeByUrl(existing.avatar)` 删磁盘+库，再写新值；旧值无记录或置空跳过，保证幂等。

### 3. 前端
- `useApi.js`：`BASE='http://localhost:3000/api'`、`ASSET_BASE` 补全绝对地址；`request` 仅非 FormData 设 JSON 头；新增 `upload(path, formData)` 与 `assetUrl(path)`。
- `HomePageManageView.vue`：头像上传控件、即时预览（`api.assetUrl`）、移除头像调用 DELETE；`.avatar img { width:100%; height:100%; object-fit:cover }`，容器 40px。
- `HomeView.vue`：`profile.avatar = api.assetUrl(data.avatar) || DEFAULT_AVATAR`，`<img @error>` 回退；`.terminal-body` 固定高度（桌面 420px / 平板 400px / 手机 360px）。
- `vite.config.js`：加 `/files` 代理到 `http://localhost:3000`。

### 4. 工程化
- 根 `.gitignore` 增加 `files/`。
- `docker-compose.yml`：PostgreSQL 16 + pgAdmin（当前项目实际用 SQLite，未接入，仅作外部依赖示例）。
- OpenSpec 提案 `changes/homepage-avatar-upload`（proposal/design/tasks/specs）本次会话中已整体归档至 `changes/archive/homepage-avatar-upload`。

## 错误与修复
- 上传报 `Unexpected token '-' ... is not valid JSON` → useApi 强制 JSON 头导致 FormData 误解析，改为非 FormData 才设头。
- 保存头像后首页不更新 → Vite(5173) 未代理 `/files`，相对路径 404；加 `assetUrl` 绝对地址 + vite `/files` 代理。
- 预览头像过大 → `.avatar img` 加尺寸约束。
- 代码框高度：多次调整（调大→固定→+200px→-100px），最终固定高度不随内容撑高。
