# 墨堆 · 文章列表页设计说明

## 设计目标

在保持现有文章详情页视觉风格一致的前提下，为「墨堆」增加一个具备**多级分类（最多三级）**能力的文章列表功能，使用户能够沿 `一级 / 二级 / 三级` 的层级路径（如 `NodeJS / 数据库 / Mysql数据库`）精确浏览内容。

---

## 风格继承

### 1. 整体气质
- **极简留白**：延续详情页的大量留白与宽松呼吸感，避免信息拥挤。
- **东方编辑感**：标题使用衬线体，正文使用无衬线体，营造中文博客特有的书卷气。
- **黑白骨架 + 森绿强调**：以黑、白、灰为主色，森绿（`#2d8264`，深色模式 `#5fc59a`）作为唯一强调色，用于激活态、链接与交互高亮；彩色封面图保留为界面中的色彩来源。
- **清晰层级**：通过字号、字重、色温和间距建立阅读节奏。

### 2. 顶部导航
- 左侧品牌名「墨堆」使用衬线体加粗。
- 右侧导航：首页、文档、简历、茶馆，当前页「文档」底部带品牌色下划线。
- 保留主题切换按钮，与详情页行为一致。

---

## 新增功能：多级分类（最多三级）

### 分类树（左侧导航）
将一维标签栏升级为**可展开/折叠的层级分类树**，置于页面左侧独立栏，支持最多三级嵌套：

```
NodeJS
├─ 数据库
│  ├─ Mysql数据库      ← 三级（叶子）
│  └─ MongoDB          ← 三级（叶子）
└─ 框架
   ├─ Express
   └─ Koa
AI 工程化
├─ 规格化开发
│  ├─ openSpec         ← 三级（叶子）
│  └─ 规范文档
└─ 模型部署
   └─ 推理优化
设计洞察 / 产品思考 / 生活随笔   ← 一级（无子级示例）
```

**视觉规则**：
- 层级通过**左侧竖线 + 逐级缩进**体现，最多三级缩进。
- 含子级的节点带**展开/折叠箭头**（点击箭头切换，不触发筛选）。
- 每个节点右侧显示**该节点下文章数**（含子孙），让用户预判内容量。
- 当前选中节点以**品牌色高亮 + 左侧色条**标记，未选中为灰字。
- 桌面端树栏 `sticky` 固定，超长时内部滚动。

**交互**：
1. 点击**节点标签** → 筛选该节点及其所有子孙文章（如点击「数据库」会显示 Mysql、MongoDB 全部文章）。
2. 点击**箭头** → 仅展开/折叠子树，不筛选。
3. 点击「清空」或面包屑「全部」→ 重置为全部文章。
4. 无匹配文章时显示**空状态**提示。
5. 文章卡片右上角标签显示**末级分类名**（如 `openSpec`），面包屑显示**完整层级路径**。

### 面包屑路径
位于文章列表上方，实时反映当前所选分类的层级路径，任意层级均可点击回退：

```
全部 / NodeJS / 数据库 / Mysql数据库
```

- 当前层级以深色加粗显示，历史层级为可点击链接。
- 与左侧分类树**双向联动**：树选中 → 面包屑更新；面包屑回退 → 树高亮同步。

## 文章卡片结构

每张卡片为可点击的整体链接：

```
┌──────────────────────────────────────┐
│  [封面图]    分类标签                  │
│              文章标题（衬线体）        │
│              摘要（2 行截断）          │
│              作者 · 日期 · 阅读量      │
└──────────────────────────────────────┘
```

- **封面图**：4:3 比例，圆角，营造杂志感。
- **标题**：22px 衬线体，悬浮时变为品牌色。
- **摘要**：14px 灰色正文，最多两行，保持列表页清爽。
- **元信息**：作者、发布时间、阅读量，使用 13px 浅灰图标+文字。

---

## 右侧边栏

延续详情页右侧边栏的信息架构，提供辅助导航：

1. **热门标签**：云状标签入口，支持点击筛选。
2. **最近更新**：4 篇最新文章，含发布日期。
3. **按月归档**：时间维度入口，显示每月文章数。

## 响应式策略

| 断点 | 布局变化 |
|------|----------|
| ≥1180px | 三栏：左 248px 分类树 + 中文章列表 + 右 300px 侧边栏 |
| 1024px–1179px | 三栏收窄：左 220px + 中 + 右 280px，栏间距 24px |
| 768px–1023px | 单栏，顺序为：分类树（可折叠）→ 文章列表 → 侧边栏（底部卡片网格） |
| ≤768px | 卡片改为上下布局（封面图在上），分类树默认折叠，点击标题展开 |
| ≤480px | 隐藏顶部导航链接，保留品牌与主题切换 |

## 无障碍与性能

- 所有交互元素支持键盘聚焦，聚焦环使用品牌色。
- 分类树使用语义化 `nav` 容器，节点为可点击 `div` 并支持 Tab 聚焦。
- 展开/折叠箭头与节点选择分离，避免误操作；折叠状态不丢失筛选。
- 图片使用 `alt=""` 装饰性图片，避免屏幕阅读器冗余播报。
- 暗色模式基于 `prefers-color-scheme` 与 `localStorage` 记忆。
- 使用 CSS 自定义属性实现主题切换，无闪烁。
- 卡片悬浮动画仅使用 `transform` 与 `opacity`，避免触发重排。
