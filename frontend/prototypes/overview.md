# 文章列表页设计概览

## 完成内容

基于用户提供的文章详情页截图，为「墨堆」设计了同风格的文章列表功能，并实现了可交互的高保真原型。

## 关键决策

- **风格延续**：保持极简留白、东方编辑感、黑白灰主色 + 暖橙强调色，与现有详情页一致。
- **多级分类树（最多三级）**：左侧独立分类树，支持 `一级 / 二级 / 三级` 嵌套（如 `NodeJS / 数据库 / Mysql数据库`），含展开/折叠箭头与每节点文章数。
- **面包屑联动**：文章列表上方显示完整层级路径，与分类树双向同步，任意层级可点击回退。
- **卡片布局**：采用封面图 + 末级分类 + 标题 + 摘要 + 元信息的结构，悬浮时标题高亮、卡片微抬升。
- **右侧边栏**：保留热门标签、最近更新、按月归档三块辅助信息，与详情页侧边栏逻辑一致。
- **响应式适配**：三栏桌面布局（分类树 + 列表 + 侧边栏）平滑过渡到移动端单栏，分类树可折叠。
- **暗色模式**：支持系统偏好记忆与手动切换。

## 文章详情页目录升级（三级导航）

在 `article-detail.html` 中，将原本扁平的二级（仅 h2）右侧 TOC，升级为**动态生成、最多三级**的目录导航，与详情页的「多级分类」设计语言保持一致。

### 关键改动
- **目录由 JS 从正文标题自动构建**：扫描 `.content` 内的 `h2 / h3 / h4`，生成嵌套 `<ul>` 树，标题与目录 id 永不脱节。
- **三级视觉层级**：逐级缩进（14px 阶梯）+ 逐级字号递减（14 / 13.5 / 13px）+ 三级灰阶降透明度；每级左侧保留引导竖线。
- **滚动高亮（scroll-spy）**：高亮当前所在小节，并给其祖先链（h2→h3）加 `branch` 浅色标记，使用户始终知道自己在三级树中的位置。
- **正文补齐三级结构**：在「核心概念」「从零开始一个规格」下新增 h3/h4，使三级目录有真实内容可演示。
- **侧栏滚动**：`.toc` 加 `max-height: calc(100vh - 116px)` 与内部滚动 + 细滚动条，长目录不会溢出视口。
- 沿用原有森绿强调色（`#2d8264` / 深色 `#5fc59a`）、衬线标题、暗色模式与主题切换，风格零割裂。

### 验证建议
- 浏览器打开 `article-detail.html`，确认右侧目录出现 h2/h3/h4 三级缩进。
- 滚动页面，确认当前小节高亮且祖先层级以浅色标记。
- 点击任意三级目录项，确认平滑滚动且落点不被顶栏遮挡（scroll-margin-top: 90px）。
- 切换暗色模式，确认三级文字对比度仍满足可读。

## 列表页右侧「动态」栏改造

在 `article-list.html` 中，将右侧栏由原来的「更新时间线」标题（时钟图标 + 文字 + 动态标签）改造为以「动态」为核心的标题区。

### 关键改动
- **移除「更新时间线」**：删除原标题文字与时钟图标。
- **「动态」改为按钮**：原右侧「动态」标签变为胶囊按钮，置于栏头最左侧作为标题；hover 高亮森绿、含 `focus-visible` 焦点环。
- **刷新按钮**：「动态」右侧新增圆形刷新按钮（refresh 图标）；点击时图标旋转 360° 并重新按日期排序动态列表（带淡入淡出过渡）。
- **折叠/展开**：「动态」按钮可点击折叠/展开动态列表，带 `aria-expanded` 无障碍标记。
- 下方更新列表保留，作为「动态」内容流，视觉与交互风格与全站一致。

### 验证建议
- 浏览器打开 `article-list.html`，确认「更新时间线」文字已消失，栏头为「动态」按钮（最左）+ 刷新按钮（右）。
- 点击刷新按钮，确认图标旋转、列表淡入淡出并重排。
- 点击「动态」按钮，确认列表可折叠/展开，且 `aria-expanded` 状态同步。
- 切换暗色模式，确认按钮对比度与 hover 态正常。

## 全站 Logo 替换

将 7 个 HTML 页面（`index` / `article-list` / `article-detail` / `resume` / `digital-life` / `about-me` / `xiaoji`）顶部 `.brand-mark` 中的内联 SVG logo 统一替换为新提供的 `logo.png`（138×138，森绿双层几何图形）。新 logo 与「黑白 + 森绿」主题一致，浅色块与深色块对比明显。

### 关键改动
- **新增资产**：`logo.png` 放在项目根目录，所有页面以相对路径 `logo.png` 引用，零外链。
- **SVG → IMG**：原 6 行内联 SVG（28×28 圆角绿底 + 三个白条）替换为单行 `<img src="logo.png" width="30" height="30">`；`.brand-mark` 的 30×30 框架不变，桌面/移动 (26×26) 尺寸规则保持。
- **CSS 兼容**：原 `.brand-mark svg` 规则扩展为 `.brand-mark svg, .brand-mark img { width:100%; height:100%; display:block }`，新旧资产可共存，便于将来切回 SVG。
- **未触及**：digital-life.html 聊天区中作为「机器人头像」的 SVG（`viewBox="0 0 28 28"` JS 模板）与品牌 logo 无关，保留原样。

### 验证建议
- 打开任意一个 HTML，确认顶栏品牌区显示新绿色几何 logo，文字「墨堆」保持不变。
- 切换白天/夜晚主题，确认 logo 在两种背景下都清晰可辨（PNG 自身已含深浅两色块，无需滤镜）。
- 调整窗口至移动端断点（≤720px），确认 logo 自动缩小为 26×26，布局不抖动。
- 浏览器 Network 面板确认 `logo.png` 是同源加载、无 404。
